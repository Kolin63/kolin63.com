JSMN-Iterator is a small C-library I made for iterating over JSMN data.

JSMN is a C-library for parsing JSON (Javascript Object Notation - JSON is widely used for save data, config files, etc).

JSMN is great because it's extremely fast and lightweight - but it doesn't have a very extensive API. Honestly, it's not even usable on its own. So, I made JSMN-Iterator so that it is usable!

If you don't know what iteration is, it means doing some operation on each object in a list of objects. That's what JSMN Iterator does. Very simple, but very useful!
