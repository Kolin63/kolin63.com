Redstone IBM Monitor

Home Projects Resume Blog Gallery

I really like retro computing, and I really like redstone, so I decided to recreate the 5151 monitor in Minecraft. I did this with a large array of map displays and a bunch of massive ROM's. The input is handling through hexadecimal-encoded data via music disks in shulkers, which can be generated through a Python script.

Don't worry, I didn't fill out the ROM's by hand! That would have taken at least a decade. Instead, I used a Python library called Litemapy to generate Litematica schematics.

Unfortunately, it is not quite a truthful recreation. The font is exactly the same, but the screen is a fraction of the size.

I was originally going to make the full 80x25 screen, but it was EXTREMELY laggy. Even with the smaller screen, the entire game turns into a slideshow.

Despite these limitations, I still had a lot of fun making this. It taught me a lot about optimizing redstone (or, failing to) and about IBM computers.

I don't have much to show for this right now- I have everything on private GitHub repos because it's all a pretty big mess (and it's not easy to put a Minecraft world into Github), but making a YouTube video to showcase this is on my todo list. Coming soon!
