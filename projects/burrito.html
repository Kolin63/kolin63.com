Burrito is a Neovim plugin made to wrap text files.

Vim is an extremely powerful text editor, but I sometimes get bothered with how it handles lines of text (by this I mean plain English, not code). Vim mostly operates on a line-by-line basis, so it is completely useless if everything is in one line, even if it is visually wrapped.

There are some ways to hard-wrap or soft-wrap text at a certain column, which usually works fine.

The problem arises when you are writing in markdown. Then, you want the text files to actually look good and you don't want any formatting to break.

Burrito is made specifically for markdown to avoid these problems. For example, Burrito is aware of headers, lists, code blocks, paragraphs, etc.
