This was my entry for GMTK 2024. It's a Wordle-roguelike, and it runs in the terminal (Windows only). At some point I also decided that it should look like a Pip-Boy.

I had a lot of fun making this, but man, the code SUCKS. I'm pretty sure this was the first project I ever made in C++ (check out learncpp.com!), and I had no idea what I was doing.

This was also very fun because I was on a time crunch. GMTK is 96 hours, but I had only a little more than 48. That's because on the third day, I was getting on a bus to go to band camp, where there was no WiFi and barely any free time. So, I had to be done before then.

I stayed up really late the night before, grinding out this game. It was a really fun time! I've mostly stopped doing game jams, but I miss doing stuff like that.

Well, you know what they say. If it works, it works. The thing is, this game usually doesn't work.

If you want to try to play, I won't stop you, but I can't make any guarentees. You can download the Windows executable here.

Since you probably won't be able to run this, there are photos on my Itch.
