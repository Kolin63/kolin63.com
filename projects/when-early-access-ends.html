Itch

This was made from the Brackey's 2024.2 game jam. It's a Warioware-like game about my real life personal conflicts at the time.

I made this with the Godot game engine in GDScript.

Honestly, I think I could have had a better idea for the game. I feel like game jam games that are about making the game is a bit of a cliche and can get stale. Nevertheless, I still had fun making this and I have fun replaying it every once in a while!

Anyways, this game is not entirely about the game jam. It is also about Satisfactory, a video game I really like. Before that September, Satisfactory had been in Early Access for years. Finally, it's 1.0 release date was announced, but it overlapped with the Brackey's dates.

Of course, playing Satisfactory took priority. So, I had less time to make my jam entry, which is what the story of the game is about. Again, I think that this is a big cliche, but again, I still had fun.

You can play the game on Itch.
