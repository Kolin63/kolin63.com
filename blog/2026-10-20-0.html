So I've been Googling my name, and it's a lot of fun! This website shows up, along with my GitHub, my LinkedIn, and some other things.

The only thing is that the Google search AI is aware of this blog. I really don't want to have to move this to some social media website like Tumblr or something, so I just finished doing some research and updating my blog pages.

What I did was add a "noindex" meta tag to the header of all the blog html files. Hopefully, this should prevent Google from crawling here.
